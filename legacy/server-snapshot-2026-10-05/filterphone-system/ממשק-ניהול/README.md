# ממשק ניהול - FilterPhone

Dashboard ניהול למערכת סינון תוכן FilterPhone.

## טכנולוגיות
- React 19 + Vite
- Dark Mode עברית RTL
- Inline Styles (ללא Tailwind/CSS frameworks)

## התקנה והרצה

```bash
npm install
npm run dev
```

הממשק יעלה על פורט **3000**.

> **חשוב:** ודא שהשרת המרכזי פועל על פורט 3001 לפני פתיחת הממשק.

## דפים

### מסך התחברות
- כניסה עם אימייל + סיסמה
- הפניה אוטומטית לפי תפקיד (מנהל/לקוח)

### Dashboard מנהל
- **סקירה** - סטטיסטיקות, גרפים, פעילות אחרונה
- **לקוחות** - ניהול מלא (יצירה, עריכה, מחיקה, שינוי רמה/סטטוס)
- **בקשות** - אישור/דחיית בקשות לקוחות
- **לוגים** - צפייה בלוג פעילות מלא

### פורטל לקוח
- צפייה בסטטוס, רמת סינון, מנוי
- סטטיסטיקות אישיות
- שליחת בקשות למנהל
