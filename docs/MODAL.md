# שרת GPU של Modal לסינון תמונות — מדריך פשוט

מיועד למי שלא מבין בתכנות. **לא צריך מחשב עם Python ולא צריך טרמינל** — הכול דרך האתרים
(Modal, GitHub, והדשבורד של FilterPhone). בערך רבע שעה, פעם אחת.

## מה זה ולמה

היום סינון התמונות רץ על המעבד של השרת. ב-Modal יש כרטיסי מסך (GPU) חזקים, שמנתחים תמונות הרבה
יותר מהר. החיבור בנוי כך ש:

- **איכות הסינון זהה לחלוטין:** Modal מריץ את **אותו קוד ואותם מודלים** בדיוק, ומחזיר לשרת רק את
  הציונים. ההחלטה (לחסום / לצבוע / להעביר) נעשית בשרת שלנו — באותו קוד כמו היום. נבדק אוטומטית:
  לכל סוג תמונה ובכל רמה, ההחלטה דרך Modal זהה להחלטה המקומית.
- **מטמון:** תמונה שכבר נבדקה פעם אחת לא נשלחת שוב — יוצאת מיד מהזיכרון.
- **נפילה אוטומטית:** אם Modal לא עונה, איטי, או שנגמר הקרדיט — אותה תמונה נבדקת מיד בשרת הרגיל,
  והלקוח לא מרגיש כלום. אחרי חצי דקה מנסים שוב את Modal.

---

## שלב 1 — חשבון ב-Modal
1. נכנסים ל-**https://modal.com** ← **Sign up** (אפשר עם חשבון Google או GitHub).
2. **חשוב — תקרת הוצאות:** ב-**https://modal.com/settings/usage** (או Settings ← Usage / Billing)
   מגדירים תקרה (Budget / Spend limit) של **0$ מעבר לקרדיט החינמי**. כך אף פעם לא יהיה חיוב — כשהקרדיט
   נגמר, Modal פשוט מפסיק לענות, והסינון חוזר לבד לשרת הרגיל.

## שלב 2 — מפתח להעלאה (פעם אחת)
1. ב-Modal: **Settings ← API Tokens ← New Token**. מקבלים שני ערכים: **Token ID** ו-**Token Secret**.
2. ב-GitHub, בפרויקט filterphone: **Settings ← Secrets and variables ← Actions ← New repository secret**.
   יוצרים שני סודות:
   - שם: `MODAL_TOKEN_ID` — ערך: ה-Token ID
   - שם: `MODAL_TOKEN_SECRET` — ערך: ה-Token Secret

## שלב 3 — להעלות את שרת הסינון ל-Modal (לחיצה אחת)
1. ב-GitHub: לשונית **Actions** ← בצד: **"העלאה ל-Modal (שרת GPU)"** ← **Run workflow** ← Run.
2. מחכים כ-5–10 דקות (בפעם הראשונה Modal מוריד את המודלים).
3. נכנסים לריצה שהסתיימה (✓ ירוק). בסיכום מופיעה **הכתובת** שנראית כך:
   ```
   https://השם-שלך--filterphone-engine.modal.run
   ```
   מעתיקים אותה.

## שלב 4 — טוקן גישה (כדי שרק השרת שלנו יוכל לפנות ל-Modal)
1. ב-Modal: **Settings ← Proxy Auth Tokens ← New token** (זה **לא** אותו טוקן משלב 2).
2. מקבלים **Token ID** (מתחיל ב-`wk-`) ו-**Token Secret** (מתחיל ב-`ws-`).

## שלב 5 — לחבר בדשבורד
1. בדשבורד של FilterPhone: **מערכת ← "שרת GPU לסינון תמונות (Modal)"**.
2. מדביקים: את הכתובת משלב 3, ואת Token ID + Token Secret משלב 4. מצב: **"תמיד"** (או "רק כשהשרת
   עמוס" — ראו עלויות למטה).
3. **שמירה**, ואז **"בדיקת חיבור"**. בפעם הראשונה זה יכול לקחת עד דקה (Modal מעלה את המודלים
   לכרטיס). צריך להופיע: **✓ מחובר**.

זהו. המנוע קולט את ההגדרות לבד תוך כ-15 שניות, בלי הפעלה מחדש. בכרטיס "בריאות השרת" רואים כמה
תמונות נותחו ב-GPU וכמה חזרו לשרת הרגיל.

---

## עלויות — חשוב לדעת (בכנות)

- Modal מחייב **לפי זמן שהכרטיס דולק**, לא לפי תמונה. הכרטיס נכבה לבד אחרי 3 דקות בלי תמונות.
- הכרטיס שבחרנו (T4) עולה בערך **0.6$ לשעה** (המחיר המדויק: https://modal.com/pricing).
  כלומר 30$ קרדיט חינמי ≈ **כ-50 שעות** של כרטיס דולק בחודש.
- כשיש לקוחות שגולשים כל היום, הכרטיס כמעט לא נכבה — והקרדיט יכול להיגמר תוך כמה ימים. **זה לא
  מזיק:** כשהוא נגמר, הסינון חוזר אוטומטית לשרת הרגיל (ועם תקרת הוצאות — בלי חיוב).
- כדי שהקרדיט יספיק לכל החודש: בדשבורד בוחרים מצב **"רק כשהשרת עמוס"** — Modal ייכנס לפעולה רק
  בשעות העומס, כשהשרת הרגיל מתחיל לחכות בתור. זה בדיוק המקום שבו ה-GPU הכי עוזר.

## שאלות נפוצות

- **"בדיקת חיבור" אומרת "גרסת המודלים שונה"?** עדכנו את הקוד — מריצים שוב את שלב 3 (Run workflow).
- **"הטוקן שגוי"?** בודקים שהדבקתם את הטוקן מ-**Proxy Auth Tokens** (שלב 4), לא מ-API Tokens.
- **"הכתובת שגויה"?** הכתובת חייבת להסתיים ב-`filterphone-engine.modal.run`, ושלב 3 צריך להסתיים ב-✓.
- **רוצים לכבות?** בדשבורד: מצב "כבוי", או "הסרה". הסינון ממשיך כרגיל בשרת.
- **זה בטוח?** רק השרת שלנו, עם הטוקן, יכול לפנות ל-Modal. התמונות נשלחות מוצפנות (HTTPS),
  נבדקות בזיכרון, ולא נשמרות ב-Modal. הסוד נשמר בשרת בקובץ שרק השירות יכול לקרוא, ולא חוזר לדפדפן.

## לטכנאי (לא חובה)

- הקוד: `deploy/modal_engine.py` (השרת ב-Modal), `server/filterphone/engine/remote.py` (הלקוח),
  `Engine._remote` ב-`engine/service.py` (הנתיב בתוך המנוע).
- העלאה ידנית במקום GitHub: `pip install modal && modal setup && modal deploy deploy/modal_engine.py`.
- אפשר להגדיר גם במשתני סביבה בשרת (קודמים לדשבורד): `FP_MODAL_URL`, `FP_MODAL_KEY`,
  `FP_MODAL_SECRET`, `FP_MODAL_MODE` (always / overflow / off), `FP_MODAL_TIMEOUT_S`, `FP_MODAL_COOLDOWN_S`.
- ב-GPU מכובה TF32 (חישוב FP32 מלא), כדי שהציונים יהיו כמעט זהים לאלה של המעבד. תמונה שהציון שלה
  יושב ממש על הסף יכולה בתיאוריה לקבל החלטה שונה בהפרש של עשרות-אלפית; זה זהה לסטייה שבין שני
  מעבדים שונים.
