# שרת GPU של Modal לסינון תמונות — מדריך פשוט

מיועד למי שלא מבין בתכנות. בסוף התהליך תשלח לי שני דברים (כתובת + טוקן), ואני מחבר הכול.

## מה זה ולמה

היום סינון התמונות רץ על המעבד (CPU) של השרת הקטן. זה עובד, אבל כבד. ל-Modal יש כרטיסי GPU
חזקים, והם נותנים **קרדיט חינם כל חודש** — מספיק בשביל המון תמונות. נעביר את החישוב הכבד ל-GPU
של Modal, ונשים **מטמון**: תמונה שכבר נבדקה פעם אחת לא נבדקת שוב — יוצאת מיד מהזיכרון. ככה הסינון
נהיה גם מהיר יותר וגם זול יותר, **בלי לשנות את איכות הסינון** (אותם מודלים בדיוק). וכשנגמר הקרדיט
החודשי — הכול חוזר אוטומטית לשרת הרגיל, בלי שאף לקוח ירגיש.

> איך זה עובד מתחת לפני השטח (לא חובה להבין): Modal מריץ את **אותו קוד ניתוח** של FilterPhone ומחזיר
> תוצאה קטנה (JSON) — לא את התמונה. הציור של התמונה (ברמה 2) נשאר אצלנו, מהיר. לכן גם אם Modal
> יהיה לא זמין — הסינון ממשיך לעבוד.

## מה אתה צריך לעשות (פעם אחת, ~15 דקות)

### שלב 1 — לפתוח חשבון ב-Modal
1. היכנס ל-**https://modal.com** ולחץ **Sign up** (אפשר עם חשבון Google או GitHub).
2. זהו. הקרדיט החינמי החודשי מופעל אוטומטית. אפשר לראות אותו ב-**https://modal.com/settings/usage**.

### שלב 2 — להתקין את הכלי של Modal במחשב
צריך Python מותקן במחשב (ברוב המחשבים כבר יש). פותחים **טרמינל** (ב-Windows: "Command Prompt" או
"PowerShell"; ב-Mac: "Terminal"), ומריצים:

```bash
pip install modal
```

ואז מחברים את הכלי לחשבון שלך (זה יפתח לך דף בדפדפן לאישור — לוחצים אישור):

```bash
modal setup
```

מדריך רשמי אם נתקעת: **https://modal.com/docs/guide** ו-**https://modal.com/docs/reference/cli/token**

### שלב 3 — להעלות את שרת הסינון ל-Modal
את הקובץ שמריץ את הסינון אני מכין בתוך הפרויקט (`deploy/modal_engine.py`). כשהוא יהיה מוכן אתן לך
**פקודה אחת** בדיוק בסגנון הזה:

```bash
modal deploy deploy/modal_engine.py
```

(אם אין לך את הקוד במחשב — לא נורא, אני אשלח לך את הקובץ היחיד הזה; שומרים אותו בתיקייה ומריצים
את הפקודה מאותה תיקייה.)

בסוף הריצה Modal ידפיס **כתובת (URL)** שנראית כך:

```
https://<השם-שלך>--filterphone-engine.modal.run
```

**העתק את הכתובת הזו** — זה הדבר הראשון שתשלח לי.

### שלב 4 — ליצור טוקן (סיסמת גישה) ולשלוח לי
כדי שרק השרת שלנו יוכל לפנות ל-Modal (ולא כל אחד), יוצרים מפתח גישה:
1. היכנס ל-**https://modal.com/settings/proxy-auth-tokens** (או Settings ← Proxy Auth Tokens).
2. לחץ **Create** / **New token**. יתקבלו שני ערכים: **Token ID** (מתחיל ב-`wk-`) ו-**Token Secret**
   (מתחיל ב-`ws-`).
3. **שלח לי את שניהם יחד עם הכתובת מהשלב הקודם.**

> הערה: אם המסך הזה נראה אצלך אחרת (Modal משנים מדי פעם את הממשק), פשוט תגיד לי ואני אכוון אותך
> בדיוק לפי מה שאתה רואה. אל תשתף את הטוקן בשום מקום ציבורי — רק איתי, ואני שומר אותו כהגדרה
> מוצפנת בשרת (לא ב-git).

## מה אני עושה אחרי שאתה שולח לי את ה-URL + הטוקן

1. מגדיר ב-FilterPhone את Modal כ**ברירת המחדל** לסינון תמונות (דרך הגדרות השרת / הדשבורד).
2. מפעיל **מטמון משותף**: כל תמונה נבדקת פעם אחת בלבד; בפעם הבאה התוצאה יוצאת מהזיכרון (מהיר).
3. מגדיר **נפילה-חזרה אוטומטית**: אם Modal לא עונה, איטי מדי, או שנגמר הקרדיט החודשי — הסינון עובר
   מיד לשרת המקומי, בלי שאף לקוח יראה הבדל. כשהקרדיט מתחדש — חוזר ל-Modal לבד.
4. בדשבורד תראה כמה תמונות עברו דרך Modal, כמה דרך המטמון, וכמה נפלו חזרה למקומי.

**מה שלא משתנה:** אותם מודלים, אותם ספים, אותן רמות סינון — איכות הסינון זהה לחלוטין. Modal רק
מזרז ומוזיל.

## שאלות נפוצות

- **זה עולה כסף?** יש קרדיט חינם חודשי. נגדיר תקרה; כשמתקרבים אליה — נפילה חזרה למקומי. לא תגיע לחיוב
  בלי שתבחר בזה.
- **מה אם אני טועה באיזה שלב?** שלח לי צילום מסך של מה שאתה רואה ואני אכוון. אי אפשר "לשבור" כלום —
  עד שתשלח לי URL + טוקן, שום דבר ב-FilterPhone לא משתנה.
- **זה בטוח?** רק השרת שלנו, עם הטוקן, יכול לפנות ל-Modal. התמונות נשלחות מוצפן (HTTPS), נבדקות, ולא
  נשמרות ב-Modal.
