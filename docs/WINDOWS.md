# מחשבי Windows (FilterPhone למחשב) בשרת ובדשבורד

התוכנה למחשב נמצאת במאגר `yeled-tov/filter-phone-desktop`. היא משתמשת באותו API של הטלפון
(`/v1/enroll`, `/v1/device`, `/v1/device/vpn`, `/v1/device/heartbeat`, `/v1/device/rekey`) עם
`platform=windows`. מה שנוסף כאן:

## טאב "מחשבים" בדשבורד
- `#/computers` — רשימת מחשבי Windows בלבד (טאב "מכשירים" מציג מעכשיו רק טלפונים).
- דף מחשב: מצב כל שכבת הגנה כפי שהמחשב בדק אותה, לקוח ויומן; רמת סינון וחסימות אתרים
  (רק מה שנחסם בשרת — DNS ופרוקסי — מוצג, כי זה מה שחל על מחשב); שליטה במחשב (Chrome בלבד,
  חסימת חנות Microsoft); הפקת קוד הסרה; השבתה (= סגירת הגלישה במחשב), מחיקה.

## דיווח מהמחשב (heartbeat)
קטע `windows` בדיווח: `overall`, `edition`, `build`, `protected_since`, ומצב לכל שכבה
(`tunnel`, `server_path`, `kill_switch`, `ca_trust`, `interception`, `image_path`, `chrome_only`,
`chrome_policy`, `store_block`) — `ok` / `pending` / `failed` / `unsupported` / `unknown`. שדות אחרים
נזרקים (`sanitize_heartbeat`).

מצב התאימות של מחשב (`compliance.evaluate_windows`): אדום כשחסימת הגלישה מחוץ לסינון כבויה, בדיקת
הסינון נכשלה, התעודה חסרה, הגבלת הדפדפנים לא פועלת, או שדיווח הגיע מחוץ למנהרה בזמן שהמחשב טוען
שהמנהרה תקינה. צהוב ל-Windows Home (חסימה מראש לא אפשרית — נסגר כשנפתח), חנות לא חסומה, מנהרה
למטה (הגלישה חסומה), בדיקות שעוד רצות, או בלי דיווח. ירוק רק כשכל השכבות דווחו תקינות.

## שליטה מהדשבורד
`PATCH /v1/admin/devices/{id}` עם `{"desktop": {"chrome_only": bool, "block_store": bool}}` (דורש קוד
הורים כשמוגדר). הערכים נשמרים ב-`DeviceSettings.desktop` ונשלחים למחשב בכל תשובת heartbeat בשדה
`windows`. המחשב אוכף רק מה שמנהל המחשב אישר בזמן ההתקנה — מהדשבורד אפשר לכבות הגבלה או להחזיר
אותה, לא לכפות משהו שלא אושר.

## קודי הסרה
`POST /v1/admin/devices/{id}/removal-code` (דורש קוד הורים כשמוגדר; נרשם ב-audit וביומן המכשיר)
מחזיר `{"code": "XXXXX-XXXXX", "valid_until": epoch}`. האלגוריתם והמפתח — `api/removal.py`. המפתח
(32 בתים אקראיים, עמודה `devices.removal_key`, הגירה 15) נוצר כשהמחשב מבקש אותו
(`want_removal_key: true` בדיווח), נשלח רק בתוך המנהרה, ולא מוצג בדשבורד (רק `removal_ready`).
המחשב לא דורש קוד כשהוא לא הופעל, כשהוא נמחק בדשבורד (השרת מחזיר 401), או כשאין לו מפתח
(שרת בגרסה ישנה) — כך אף מחשב לא ננעל בלי דרך להוציא לו קוד.

## פריסה
השינויים האלה **לא הועלו לשרת**. ההעלאה ידנית בלבד (workflow "העלאה לשרת", `what=server`) אחרי
מיזוג ל-main ובדיקות ירוקות. ההגירה (עמודה חדשה) רצה לבד בעליית השרת ואינה משנה נתונים קיימים;
חזרה לגרסה קודמת לא נפגעת מהעמודה הנוספת.
