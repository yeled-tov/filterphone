# FilterPhone — סלוגן, סרטון ותוכנית הפצה

## 1. הסלוגן

**המומלץ: "מסננים — לא חוסמים."**
ותת-סלוגן קבוע: **"הטלפון נשאר חכם. התוכן נשאר נקי."**

למה: שלוש מילים, ניגוד ברור מול "סינון רגיל" (שחוסם הכול), והוא אומר בדיוק מה שמבדל אתכם — סינון
תמונות חכם במקום לחנוק את הטלפון. קל לזכור, קל לחזור עליו בכל פרסום.

חלופות (אם רוצים טון אחר):
- "כל תמונה נבדקת. שום דבר לא נשבר."
- "רואים רק את מה שראוי."
- "טלפון כשר — בלי לוותר על הטלפון."
- "שומרים על העיניים, לא על המגבלות."

## 3. תוכנית ההפצה

**העיקרון:** אותו מסר בכל מקום — *מסננים, לא חוסמים* + *סינון תמונות חכם* + *הטלפון לא נשבר* — ותמיד
מסתיימים בקישור: **https://www.filterphone.com** (והורדה ישירה: https://api.filterphone.com/download/FilterPhone.apk).

### מה הופך את הדרן / עסקן למותג מוכר — ומה זה אומר בשבילכם
1. **הכשר / המלצה רבנית מוכרת** — בציבור החרדי זה שער הכניסה. שווה לפנות לגוף הכשר מוכר לתקשורת ולרבני
   קהילות באשדוד, ולהציג את הסינון (לבקש בדיקה, ולהדגיש: אי אפשר להסיר, סינון תמונות, חסימת נקודה חמה).
2. **רשת חנויות ומתקינים** — רוב הלקוחות מגיעים דרך חנות סלולר. להציע לחנויות ולמתקינים עמלה על כל לקוח
   (קוד משווק אישי) — כל חנות כזו היא סניף.
3. **נוכחות קבועה** — מודעות חוזרות באתרי החדשות ובעיתונים, לא קמפיין חד-פעמי.

### הערוצים — לפי סדר עדיפות

| ערוץ | מה עושים | כמה |
|---|---|---|
| **סטטוס וואטסאפ** (שלך + של לקוחות מרוצים) | הסרטון, ובימים אחרים תמונות הסטטוס / טיפ / "אפליקציה של השבוע" בחנות | 3–4 בשבוע |
| **ערוץ וואטסאפ "FilterPhone"** | ערוץ חדש: עדכונים, טיפים, אפליקציות חדשות בחנות, שאלות נפוצות. הקישור לערוץ בכל הודעה ובחתימה | 2 בשבוע |
| **קבוצות וואטסאפ** | קבוצות שכונה, בית כנסת, הורים במוסדות, בוגרי ישיבות — **רק באישור מנהל הקבוצה** (הודעות לא מבוקשות עלולות לחסום את המספר) | פעם בחודש לקבוצה |
| **חבר מביא חבר** | הודעה ללקוחות קיימים: הנחה / חודש חינם על כל חבר שמצטרף | פעם אחת + תזכורת בחגים |
| **אתרי חדשות חרדיים** | באנר + כתבה ממומנת: בחדרי חרדים, כיכר השבת, JDN, המחדש | חודש ראשון: שבוע בכל אתר |

| **יוטיוב** | הסרטון כשורט + סרטוני התקנה קצרים לפי יצרן (סמסונג / שיאומי) — עוזרים גם למדריך באתר ולבוט | סרטון בשבוע בחודש הראשון |
| **פייסבוק / אינסטגרם** | לקהל דתי-לאומי ומסורתי: פוסט + מודעה ממוקדת לפי ערים | לפי תוצאות |
| **בשטח** | פלאיירים עם QR בבתי כנסת וכוללים, ערב הורים במוסדות ("איך שומרים על הילדים בטלפון"), עמדה בחנויות סלולר | חודשי |

### 4 השבועות הראשונים
1. **שבוע 1** — פתיחת ערוץ וואטסאפ, הסרטון בסטטוס, הודעת "חבר מביא חבר" ללקוחות, פרופיל עסק בגוגל.
2. **שבוע 2** — קמפיין גוגל, פנייה לחנויות סלולר ומתקינים (עמלה), פנייה לגוף הכשר / רבנים.
3. **שבוע 3** — באנר וכתבה ממומנת באתר חדשות אחד; סרטוני התקנה ביוטיוב; קבוצות באישור מנהלים.
4. **שבוע 4** — בודקים מה הביא הכי הרבה פניות (שואלים כל לקוח "מאיפה שמעת?" — הבוט יכול לשאול) ומכפילים
   את התקציב שם.

**מדידה:** כמה הורדות, כמה הרשמות באפליקציה, כמה פניות לבוט בשבוע. כדאי קישור נפרד לכל ערוץ
(למשל `filterphone.com/?src=status`, `?src=google`) כדי לדעת מה עובד.
