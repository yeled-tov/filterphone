# בוט הוואטסאפ של FilterPhone

בוט שמחובר ל**וואטסאפ שלך** (כמו וואטסאפ ווב, ב-QR) ועונה ללקוחות עם AI — לפי המחירים, הכתובת ושעות
הפעילות שלך. מבוסס `whatsapp-web.js`. רץ בשרת כשירות `fp-wabot`, ו**הכול מנוהל מהדשבורד**:
עמוד **"בוט וואטסאפ"** בתפריט.

> ⚠️ **API לא-רשמי** של וואטסאפ — יש סיכון שוואטסאפ יגביל או יחסום את המספר. הבוט מתנהג כמו נציג:
> עונה רק למי שכותב, בקצב אנושי (מקליד…, השהיה), ומעביר אליך. אין בו ואין להוסיף לו מנגנונים
> "להתחמק" מזיהוי. השימוש באחריותך.

## חיבור (פעם אחת, 2 דקות)

1. **מפתח AI:** https://aistudio.google.com/apikey → Create API key (חינם, עם חשבון גוגל).
   בדשבורד → בוט וואטסאפ → מדביקים ב"מפתח" → **שמירה** → **בדיקת מפתח**.
2. מדליקים **"הבוט פעיל"** → שמירה. תוך כמה שניות מופיע QR בדשבורד.
3. בטלפון: וואטסאפ (ביזנס) → ⋮ → **מכשירים מקושרים** → **קישור מכשיר** → סורקים.
4. בוואטסאפ ביזנס: **צ'אטים → רשימות → ＋ → רשימה בשם "בוט"** (אם עוד אין).

ההתקנה בשרת אוטומטית (`deploy/wabot_install.sh`, חלק מכל העלאה): Node, Chromium, משתמש `fpbot`,
טוקן בין הבוט לשרת, ושירות systemd. בהעלאה הראשונה הבוט הישן (pm2) נעצר, והחיבור לוואטסאפ ומפתח
ה-Groq שלו עוברים לבוט החדש — בלי לסרוק שוב.

## ניהול מתוך הוואטסאפ — הרשימה "בוט"

| מה קורה | מה הבוט עושה |
|---|---|
| לקוח חדש כותב (מעולם לא כתבת לו) | מוסיף אותו לרשימה "בוט" ועונה |
| נכנסת לשיחה וכתבת בעצמך | מוציא אותה מהרשימה — זז הצידה |
| בשיחה: הכפתור למעלה (רשימות) → מסמנים "בוט" | חוזר לשיחה; אם הלקוח מחכה — עונה לו |
| לקוח מבקש נציג / שיחה ארוכה מדי | מוציא מהרשימה ושולח לך סיכום |
| שיחה קיימת שלך / איש קשר שמור | לא נוגע (אלא אם סימנת "בוט") |

בלי רשימה (וואטסאפ רגיל, לא ביזנס): הבוט עונה לכולם, ושותק בשיחה שבה כתבת לזמן שנקבע בדשבורד.

## מצב השוואה (ברירת מחדל)

כל עוד יש בוט אחר על אותו מספר — הבוט שלנו **לא שולח כלום ללקוחות** ולא נוגע ברשימות. לכל הודעת
לקוח הוא שואל את ה-AI מה היה עונה, ורושם בדשבורד (בוט וואטסאפ → "השוואה מול הבוט הקיים") ליד מה
שנשלח בפועל מהמספר. כשמרוצים — מכבים "מצב השוואה" והבוט מתחיל לענות (ואז כדאי לכבות את הבוט הישן,
אחרת שניהם יענו).

## יציבות החיבור

- החיבור לוואטסאפ נשמר בשרת (`/home/fpbot/wabot/auth`) — העלאות ועדכונים לא מחייבים סריקה חוזרת.
- באג ידוע בספרייה ("מחובר" בוואטסאפ אבל הבוט נתקע על "מתחבר"): תיקון בקוד (`lib/wwebjs_patch.js`),
  ואם בכל זאת לא נטען תוך 2 דקות — הבוט מאתחל את עצמו בלי סריקה. אחרי 3 כישלונות ברצף עובר לבד
  ל-Chrome בגרסה קבועה (Chrome for Testing). Chromium מ-snap "מוקפא" — לא מתעדכן ברקע.
- יומן אחרון מוצג בדשבורד. אבחון מלא: GitHub → Actions → "העלאה לשרת" → `wabot`.

## עוד

- **שעות פעילות** (מהדשבורד; שישי עד שעה מסוימת, שבת סגור): בשעות — אם אתה פעיל, הבוט מחכה 5 שניות
  לפני שעונה. מחוץ לשעות — עונה מיד ואומר מתי חוזרים.
- **תפריט:** כותבים `בוט` בצ'אט עם עצמך — עצירה/הפעלה לכולם, סטטוס, עצירה/החזרה של לקוח לפי מספר.
- **פניות מהאפליקציה:** מגיעות לצ'אט עם עצמך. "השב" עליהן, או `#<מספר מכשיר> טקסט` — והתשובה מגיעה
  ללקוח באפליקציה.
- **לקוח קיים (לפי הטלפון):** חסימה — הבוט מבצע לבד; פעולה רגישה (השהיה/פתיחה) — רק נרשמת לאישורך
  בדשבורד → בקשות.
- **כתובת:** שורה במידע העסק שמתחילה ב-`כתובת:` — הבוט שולח גם קישור לוויז ולמפות.

## תקלות

```bash
journalctl -u fp-wabot -n 80          # לוג הבוט
systemctl restart fp-wabot            # הפעלה מחדש (החיבור נשמר)
```
החיבור נשמר ב-`/home/fpbot/wabot/auth`. כדי להתחבר ממספר אחר: בטלפון — "התנתקות" מהמכשיר המקושר,
והדשבורד יציג QR חדש.

## פיתוח

```bash
npm test                               # בדיקות יחידה (שעות, AI, רשימה, זיכרון)
FP_API=http://127.0.0.1:8090 FP_WA_BOT_TOKEN=... node index.js
```

| משתנה | ברירת מחדל | מה |
|---|---|---|
| `FP_API` | http://127.0.0.1:8090 | שרת FilterPhone |
| `FP_WA_BOT_TOKEN` | — (חובה) | הטוקן (נוצר בהתקנה, ב-/etc/filterphone/filterphone.env) |
| `FP_WABOT_DATA` | ./data | זיכרון השיחות והחיבור לוואטסאפ |
| `CHROME_PATH` | אוטומטי | Chromium |

## פרטיות

הבוט שומר רק היסטוריה קצרה לכל שיחה (16 הודעות אחרונות, להקשר). מפתח ה-AI נשמר בשרת ולא חוזר
לדפדפן. הפניות מהאפליקציה נשמרות בשרת כמו כל פנייה בצ'אט התמיכה.
