# בוט הוואטסאפ של FilterPhone

בוט שמחובר ל**וואטסאפ שלך** (כמו וואטסאפ ווב, ב-QR) ועונה ללקוחות עם AI — לפי המחירים, הכתובת ושעות
הפעילות שלך. מבוסס `whatsapp-web.js`. רץ בשרת כשירות `fp-wabot`, ו**הכול מנוהל מהדשבורד**:
עמוד **"בוט וואטסאפ"** בתפריט.

> ⚠️ **API לא-רשמי** של וואטסאפ — יש סיכון שוואטסאפ יגביל או יחסום את המספר. הבוט מתנהג כמו נציג:
> עונה רק למי שכותב, בקצב אנושי (מקליד…, השהיה), ומעביר אליך. אין בו ואין להוסיף לו מנגנונים
> "להתחמק" מזיהוי. השימוש באחריותך.

## חיבור (פעם אחת, 2 דקות)

1. **מפתח AI:** https://aistudio.google.com/apikey → Create API key (חינם, עם חשבון גוגל).
   בדשבורד → בוט וואטסאפ → מדביקים ב"מפתח" → **שמירה** → **בדיקת מפתח**.
2. מדליקים **"הבוט פעיל"** → שמירה. תוך כמה שניות מופיע QR בדשבורד.
3. בטלפון: וואטסאפ (ביזנס) → ⋮ → **מכשירים מקושרים** → **קישור מכשיר** → סורקים.
4. בוואטסאפ ביזנס: **צ'אטים → רשימות → ＋ → רשימה בשם "בוט"** (אם עוד אין).

ההתקנה בשרת אוטומטית (`deploy/wabot_install.sh`, חלק מכל העלאה): Node, Chromium, משתמש `fpbot`,
טוקן בין הבוט לשרת, ושירות systemd. בהעלאה הראשונה הבוט הישן (pm2) נעצר, והחיבור לוואטסאפ ומפתח
ה-Groq שלו עוברים לבוט החדש — בלי לסרוק שוב.

## ניהול מתוך הוואטסאפ — הרשימה "בוט"

| מה קורה | מה הבוט עושה |
|---|---|
| לקוח חדש כותב (מעולם לא כתבת לו) | מוסיף אותו לרשימה "בוט" ועונה |
| נכנסת לשיחה וכתבת בעצמך | מוציא אותה מהרשימה — זז הצידה |
| בשיחה: הכפתור למעלה (רשימות) → מסמנים "בוט" | חוזר לשיחה; אם הלקוח מחכה — עונה לו |
| לקוח מבקש נציג / שיחה ארוכה מדי | מוציא מהרשימה ושולח לך סיכום |
| שיחה קיימת שלך / איש קשר שמור | לא נוגע (אלא אם סימנת "בוט") |

בלי רשימה (וואטסאפ רגיל, לא ביזנס): הבוט עונה לכולם, ושותק בשיחה שבה כתבת לזמן שנקבע בדשבורד.

## מצב לימוד

הבוט לומד ממך, ומשתפר עם הזמן:

| מה קורה | מה הבוט עושה |
|---|---|
| ענית בעצמך ללקוח (שיחה של לקוח — לא משפחה/חברים) | זוכר את התשובה לשאלה של הלקוח, ובפעם הבאה עונה ככה. שולח לך "📚 למדתי" עם אפשרות לבטל |
| הבוט לא יודע (חסר מחיר / פרט) | אומר ללקוח שהוא בודק וחוזר, ושולח לך שאלה ❓ בצ'אט עם עצמך |
| "השב" על השאלה שלו עם התשובה | שולח ללקוח (בניסוח שלו) וזוכר לפעם הבאה |

לא נלמדים: אישורים קצרים ("אוקיי"), "רגע, בודק", ותשובות עם מספר טלפון. לכל תשובה הבוט לוקח רק את
השאלות הדומות (וכל העובדות) — ולא משתמש בפרטים של לקוח אחר.

**ניהול מהצ'אט עם עצמך:**

```
למד: משלוח לכל הארץ תוך 3 ימי עסקים        ← עובדה
ש: כמה עולה סינון למכשיר?                 ← שאלה ותשובה (שתי שורות)
ת: 250 ₪ חד פעמי, כולל התקנה
מה למדת                                    ← הרשימה
שכח 12                                     ← מחיקה
```

בדשבורד: בוט וואטסאפ → "מצב לימוד" — הכול ברשימה, עם עריכה, מחיקה והוספה, ושני מתגים (לומד מהתשובות
שלך / שואל אותך כשלא יודע).

## יציבות החיבור

- החיבור לוואטסאפ נשמר בשרת (`/home/fpbot/wabot/auth`) — העלאות ועדכונים לא מחייבים סריקה חוזרת.
- באג ידוע בספרייה ("מחובר" בוואטסאפ אבל הבוט נתקע על "מתחבר"): תיקון בקוד (`lib/wwebjs_patch.js`),
  ואם בכל זאת לא נטען תוך 2 דקות — הבוט מאתחל את עצמו בלי סריקה. אחרי 3 כישלונות ברצף עובר לבד
  ל-Chrome בגרסה קבועה (Chrome for Testing). Chromium מ-snap "מוקפא" — לא מתעדכן ברקע.
- הספרייה (`whatsapp-web.js`) בגרסה קבועה מתוך הפרויקט: `vendor/whatsapp-web.js-1.34.7-064a3d5.tgz` —
  הענף הראשי של הספרייה מ-28/09/2026 (כולל התיקון לשינוי של וואטסאפ `_serialized` → `$1` מ-26/09).
  הגרסה ב-npm (1.34.7, אפריל) לא כוללת אותו. עדכון: `npm pack` של commit חדש לתיקייה, ועדכון package.json.
- יומן אחרון מוצג בדשבורד. אבחון מלא: GitHub → Actions → "העלאה לשרת" → `wabot`.

## עוד

- **שעות פעילות** (מהדשבורד; שישי עד שעה מסוימת, שבת סגור): בשעות — אם אתה פעיל, הבוט מחכה 5 שניות;
  ענית — הוא זז הצידה, לא ענית — הוא עונה ועוזר. **מחוץ לשעות — הבוט הוא הנציג:** עונה ועוזר עד הסוף, בלי
  "נחזור בשעות הפעילות". רק מה שבאמת דורש בן אדם (התקנה, תיאום הגעה, תשלום) — עוזר בכל מה שאפשר ואומר
  שנציג ימשיך בשעות הפעילות.
- **הודעות קוליות ותמונות:** הודעה קולית מתומללת, ותמונה (בדרך כלל צילום מסך של שגיאה / הגדרה) מתוארת
  ב-AI שבדשבורד — והבוט עונה לפי התוכן. בתיאור התמונה אין תיאור של אנשים, רק התוכן הטכני והטקסט שעל
  המסך. סרטון — הבוט מבקש לתאר במילים. רק בשיחות שהבוט מטפל בהן (תמונות וקול של שיחה שלך לא נשלחים ל-AI).
  ביומן: `voice: transcribed` / `image: described`, ותקלה בהורדה — `media (...)`.
- **מה שהבוט למד — נכנס לכל תשובה:** כל העובדות וכל השאלות והתשובות שלמד (הדומות לשאלה קודם), ב-Gemini
  כמעט הכול (חלון גדול), ב-Groq פחות (מגבלת מילים לדקה). כך "כמה זה עולה?" עונה לפי מה שלימדת על
  "מה המחיר?" גם בלי מילים משותפות. הרשימה: דשבורד → בוט וואטסאפ → מצב לימוד, או "מה למדת" בצ'אט עם עצמך.
- **הבוט באפליקציה = אותו מוח:** אותן הוראות, אותו ידע, ואותה זיכרון שיחה (לכל מכשיר) — "ומה עם זה?"
  מובן לפי מה שנאמר קודם.
- **תפריט:** כותבים `בוט` בצ'אט עם עצמך — עצירה/הפעלה לכולם, סטטוס, עצירה/החזרה של לקוח לפי מספר,
  מה הבוט למד (7) ואיך ללמד אותו (8).
- **פניות מהאפליקציה:** מגיעות לצ'אט עם עצמך. "השב" עליהן, או `#<מספר מכשיר> טקסט` — והתשובה מגיעה
  ללקוח באפליקציה.
- **לקוח קיים (לפי הטלפון):** חסימה — הבוט מבצע לבד; פעולה רגישה (השהיה/פתיחה) — רק נרשמת לאישורך
  בדשבורד → בקשות.
- **כתובת:** שורה במידע העסק שמתחילה ב-`כתובת:` — הבוט שולח גם קישור לוויז ולמפות.
- **הודעות קוליות:** לקוח ששולח הודעה קולית — הבוט מתמלל אותה (באותו AI שבדשבורד: Gemini, או Whisper
  ב-Groq) ועונה בכתב. ההתראה אליך מציגה את התמלול עם 🎤. תמלול שלא הצליח — הבוט מבקש בנימוס לכתוב.
  הודעה קולית שאתה שולח ללקוח — הבוט זז הצידה מיד, כמו בהודעה כתובה.

## תקלות

```bash
journalctl -u fp-wabot -n 80          # לוג הבוט
systemctl restart fp-wabot            # הפעלה מחדש (החיבור נשמר)
```
החיבור נשמר ב-`/home/fpbot/wabot/auth`. כדי להתחבר ממספר אחר: בטלפון — "התנתקות" מהמכשיר המקושר,
והדשבורד יציג QR חדש.

## פיתוח

```bash
npm test                               # בדיקות יחידה (שעות, AI, רשימה, זיכרון, לימוד)
FP_API=http://127.0.0.1:8090 FP_WA_BOT_TOKEN=... node index.js
```

| משתנה | ברירת מחדל | מה |
|---|---|---|
| `FP_API` | http://127.0.0.1:8090 | שרת FilterPhone |
| `FP_WA_BOT_TOKEN` | — (חובה) | הטוקן (נוצר בהתקנה, ב-/etc/filterphone/filterphone.env) |
| `FP_WABOT_DATA` | ./data | זיכרון השיחות והחיבור לוואטסאפ |
| `CHROME_PATH` | אוטומטי | Chromium |

## פרטיות

הבוט שומר רק היסטוריה קצרה לכל שיחה (16 הודעות אחרונות, להקשר). הודעות קוליות נשלחות לתמלול רק
בשיחות שהבוט עונה בהן — לא בשיחות הפרטיות שלך; ההקלטה עצמה לא נשמרת. מפתח ה-AI נשמר בשרת ולא חוזר
לדפדפן. הפניות מהאפליקציה נשמרות בשרת כמו כל פנייה בצ'אט התמיכה. מה שהבוט למד נשמר בשרת (עד 1,000
פריטים, הישנים נמחקים) — בלי מספרי טלפון בתשובות, ואפשר למחוק כל פריט מהדשבורד או ב"שכח".
