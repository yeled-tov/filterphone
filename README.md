# FilterPhone

מערכת סינון לטלפונים: VPN (WireGuard), סינון DNS (AdGuard Home) וסינון תמונות בצד השרת (יירוט HTTPS עם mitmproxy ומודלי ראייה).

## מה לא נכנס ל-git (בכוונה)

- `.env`, מפתחות WireGuard, ה-CA של mitmproxy, סיסמאות
- מסדי נתונים (`*.db`) וסשן הוואטסאפ של הבוט (`.wwebjs_auth`)
- משקלי מודלים (`*.pt`, `*.onnx`). הם יורדים בסקריפט ההתקנה
- `node_modules`, `dist`
