# CRM FilterPhone — אפליקציית המנהל

אפליקציה **נפרדת לגמרי** מאפליקציית הסינון (`app/`): חבילה משלה (`com.filterphone.crm`), סמל ושם משלה,
קובץ APK משלה. Kotlin בלבד, בלי ספריות.

## מה יש בה

* **הדשבורד** של FilterPhone בתוך האפליקציה (רכיב ה-WebView של המערכת — בלי Chrome ובלי דפדפן), בעיצוב
  לטלפון: שורת ניווט תחתונה (סקירה, בקשות, תמיכה, מכשירים, עוד), כפתורים ושדות בגובה אצבע, טבלאות ככרטיסים.
  במסך רחב — הפריסה הרגילה. רק `api.filterphone.com` נטען בחלון; קישור לאתר אחר נפתח מחוץ לאפליקציה.
* **כניסה שנשמרת** מוצפנת בטלפון (Android Keystore) ל-30 יום (`remember` ב-`/v1/admin/login`).
* **התראות**: בקשת הצטרפות / שינוי, הודעה מלקוח בתמיכה (אחת לכל שיחה, מתעדכנת), אתר שמחכה לבדיקה.
  לחיצה על התראה פותחת את העמוד המתאים בדשבורד.
  * `WatchService` — שירות קדמי עם התראה קבועה ושקטה, בודק בשרת כל דקה (`GET /v1/admin/notifications`,
    ראו `server/filterphone/api/notify.py`). ממשיך כשסוגרים את האפליקציה מהאחרונים.
  * `StartReceiver` — חוזר אחרי אתחול / עדכון. `WatchdogReceiver` — כל ~15 דקות (גם בשינה): מחזיר את
    השירות, ואם המערכת לא מרשה — בודק בשרת בעצמו.
  * אחרי הכניסה הראשונה האפליקציה מבקשת פעם אחת לפטור אותה מחיסכון סוללה (חלון של המערכת).

## התקנה ועדכון

`deploy.yml` עם `what=crm` בונה, בודק וחותם (אותו מפתח של FilterPhone), ומפרסם בדף ההורדה
(`/download/CRM-FilterPhone.apk` + `CRM.json`). השרת מוסיף אותה כ"חובה" **רק לקטלוג של מכשיר המנהל**
(`Services.crm_release`), ו-FilterPhone (מנהל מכשיר) מתקין ומעדכן אותה שם בשקט — גם כשההתקנות חסומות
בטלפון. לקוחות לא רואים אותה בחנות. בכל פרסום ה-versionCode עולה (מספר ההרצה של deploy.yml).

## בנייה מקומית

gradle -p crm :app:testDebugUnitTest :app:lintDebug :app:assembleRelease     # Gradle 9.1, JDK 17
